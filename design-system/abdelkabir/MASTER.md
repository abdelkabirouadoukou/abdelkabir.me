# Design System — Abdelkabir Ouadoukou (MASTER)

Generated by hand following the UI UX Pro Max workflow
(pattern → style → colour → type → effects → anti-patterns → checklist).
Product type: **Developer portfolio / framework author**, creative-leaning.

## 1. Pattern
Single long-scroll narrative with one spine. Sections are *steps of one Collatz orbit* (n = 27).
Order: Hero → About → Building (@thexjs) → Projects → Skills → Math → Security → Footer.
CTA: hero (projects / GitHub) and footer (GitHub). No forms, no fake email.

## 2. Style
**Editorial brutalism + Moroccan palette.** Huge variable type, hard colour blocks that alternate
(sand / ink / cobalt / saffron), hairline rules, mono micro-labels. Motion is functional:
it explains the orbit (spine, counters) instead of decorating.
Not used: glassmorphism, gradients-on-everything, purple/pink "AI" gradients, stock illustrations.

## 3. Colour tokens
| token      | hex       | use                                         |
|------------|-----------|---------------------------------------------|
| --sand     | #EEE6D3   | default ground                              |
| --paper    | #F6F0E1   | raised surfaces on sand                     |
| --ink      | #12100D   | text on sand, dark sections                 |
| --blue     | #2A39E6   | Majorelle cobalt: accent, skills section    |
| --saffron  | #FFB300   | highlight, footer ground, peak marker       |
Contrast: ink/sand 15.9:1, sand/ink 15.9:1, white-ish/blue 7.6:1, ink/saffron 11.4:1.
Saffron is never used for text on sand (fails 4.5:1) — fills and ink-on-saffron only.

## 4. Typography
- Display: **Bricolage Grotesque** (variable: wght 200–800, wdth 75–100, opsz 12–96)
- Accent:  **Instrument Serif** (italic for emphasis words)
- Mono:    **Geist Mono** (labels, numbers, code)
Scale: fluid clamp(); hero name fitted by JS so the widest variable state never overflows.

## 5. Effects
- Lenis smooth scroll driven by the GSAP ticker (one RAF loop).
- ScrollTrigger: word reveals, scrubbed paragraph, pinned horizontal package rail, count-ups.
- Spine: live hailstone readout + drawn orbit line, `mix-blend-mode: difference` so it reads on every ground.
- React Bits–inspired: variable-font proximity name, dot-grid repulsion, scroll-velocity marquee, magnetic buttons, label cursor.

## 6. Anti-patterns avoided
- Emojis as icons · scroll-jacking without escape · text in saffron on sand
- Layout shift on font load (fallback stacks + JS fit) · hover-only information on touch
- Animations that ignore `prefers-reduced-motion`

## 7. Pre-delivery checklist
- [x] Focus states visible (3px outline, offset 4px)
- [x] `prefers-reduced-motion`: no Lenis, no reveals, static spine, no cursor, no dot motion
- [x] Pinned rail only ≥ 900px; below that it's a native scroll-snap row
- [x] Hover previews are enhancement only; every row is a real link with full text
- [x] Decorative layers `aria-hidden`; split-text headings keep an `aria-label`
- [x] 375 / 768 / 1024 / 1440 layouts considered
- [x] Cursor is additive (native cursor stays)
